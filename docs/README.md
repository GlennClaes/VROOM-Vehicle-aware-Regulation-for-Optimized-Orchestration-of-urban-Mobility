# Documentation

The visual documentation site lives in `docs-site/` and is built with Vue/Vite. It contains the assignment fit, research-paper summary, architecture, SAM AI approach, simulation dashboard, sprint process, Jira/Confluence workflow and DevOps runbook.

## Local Build

```bash
cd docs-site
npm install
npm run build
npm run preview
```

The site uses the dashboard favicon and a matching dashboard-style color palette so it looks like one product instead of a generated side page.

## Source Material

Project sources, paper references, sprint artifacts and external references are tracked in `research/SOURCES.md`.
